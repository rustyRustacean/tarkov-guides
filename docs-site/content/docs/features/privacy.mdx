A plain-language privacy policy reflecting what this site's code actually does: no accounts, no ad trackers, no tracking cookies. Progress Tracker data, theme choice, and device-sync settings live in the browser's own localStorage/IndexedDB by default.

Two third parties see any data: Liveblocks (Maps "Collaborate" sessions and cross-device Progress Tracker sync, only while active) and Vercel Web Analytics, which collects cookieless, non-identifying page-view counts.

Written from the site's actual data flows, not generic boilerplate; re-verify against the code if a new feature starts moving data off the browser.

This isn't a migration phase target; there's no legacy equivalent in either legacy repo. New content, same category as `credits`/`faq`/`external-resources`.
