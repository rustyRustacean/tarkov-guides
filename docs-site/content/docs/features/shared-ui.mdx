## Theme system

4 selectable themes, one picker. `inventory` is the default.

| id          | name              | notes                                                                                             |
| ----------- | ----------------- | ------------------------------------------------------------------------------------------------- |
| `inventory` | Inventory Grid    | Default. Grid-line background, shares Modern's card-radius tokens.                                |
| `modern`    | Modern            | Former default. Navy-blue gradient plus green accent, from tarkov-tips's original dark-mode look. |
| `midnight`  | Midnight          | Auto-follows system light/dark, no separate toggle.                                               |
| `terminal`  | Tactical Terminal | Phosphor green CRT with a scanline overlay.                                                       |

`warm-gold` and `briefing` are disabled (commented out, not deleted) so they can be restored later. A browser with one saved in localStorage falls back to the default theme.

- localStorage key: `tarkovguides.theme.v1`.
- Mechanism: a `data-theme` attribute on `<html>`, set pre-paint by a blocking script to avoid a flash of the wrong theme.
- All literal color values live in `globals.css`'s theme blocks.

## Typography

- **Bender** (`--font-brand`, always active): header wordmark and display font for `inventory`, `modern`, `midnight`. SIL Open Font License 1.1.
- **Plus Jakarta Sans** (`modern`/`midnight` body font): via `next/font/google`.
- The remaining legacy fonts (Rajdhani, Lora, Cormorant Garamond, JetBrains Mono, Bebas Neue, Anton, Special Elite, Stardos Stencil, Crimson Pro) also load via `next/font/google`.
