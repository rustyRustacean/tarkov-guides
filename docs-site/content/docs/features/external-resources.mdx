A curated list of external community sites and tools that don't belong on TarkovGuides itself: a featured Discord community banner ("The SOG") above a card grid of tools, trackers, and guides (tarkov.dev tools, Arena/3D maps, story guides, boss spawn and BTR trackers, Database for Tarkov, Seasonal Modifier Planner, Tarkov Changes), plus a multi-link "Other Discords" card.

"Other Discords" always stays last and spans 2 columns to absorb whatever remainder the card count leaves against a 3-column grid, so there's no dangling single-card row on desktop. Every card links out via a plain `<a target="_blank">`, not `TransitionLink`.

This isn't a migration phase target: there's no legacy equivalent in either legacy repo. It's new content, curated directly rather than ported.

## Status

Implemented and live at `/external-resources`, linked from the header nav as "Resources."
