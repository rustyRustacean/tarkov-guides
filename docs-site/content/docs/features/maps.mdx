Interactive map viewer, porting TarkovTrackerWB-main's Leaflet-based maps (quest markers, annotations, boss spawns, live clock, custom overlays), restyled with this project's design system. `old/tarkov-tips` contributes nothing here; its room-clearing rotation guides are excluded.

## Ported from

Rewritten clean using `react-leaflet` rather than re-wrapping vanilla Leaflet:

- `old/TarkovTrackerWB-main/src/components/maps/leaflet.js`: interactive map engine, the largest single port in the migration.
- `old/TarkovTrackerWB-main/src/lib/mapsConfig.js`: 13-map configuration and custom-map IndexedDB storage.
- `old/TarkovTrackerWB-main/src/lib/taskMarkers.js`: quest-marker overlay.
- `old/TarkovTrackerWB-main/src/components/maps/annotations.js`: freehand annotation/drawing tool.
- `old/TarkovTrackerWB-main/src/components/maps/mapHeader.js`: boss spawn-chance strip and live clock.
- `old/TarkovTrackerWB-main/src/components/maps/fullscreen.js`, `mapZoom.js`, `mapSidebar.js`, `sidebarFocus.js`: fullscreen/zoom/sidebar-focus behavior.
- `old/TarkovTrackerWB-main/src/components/maps/valuables.js`: high-value loot overlay.

## Status

Implemented and live at `/maps`, linked from the header nav and homepage feature grid. Map imagery (11 SVG plus 27 WebP, all 13 maps) ships under `public/maps/{svg,webp}/`; the SVGs are CC BY-NC-SA 4.0, noncommercial only. ## Boss strip per game mode

The boss strip follows the site-wide game mode from the header's PvP / PvE / Seasonal switch; there is no separate mode control on the Maps page. Each mode has its own rosters in tarkov.dev, fetched as `maps` for `regular`, `pve` and `pvp-season` and joined onto each regular map as `bosses`, `bossesPve` and `bossesSeason` (`bossesForMode` in `src/features/maps/lib/boss-groups.ts` picks one, falling back to `bosses` if a mode failed to load). The differences are real: PvE adds AI PMCs (BEAR and USEC, shown as two pills) and raises several boss chances, and Seasonal adds Black Division to Woods, Shoreline, Streets and Ground Zero 21+ and replaces the Raiders on Labs with it. Only bosses are taken per mode: extracts are the same set in every mode and raid lengths only differ on variant entries the page doesn't show (checked 2026-11-07).

Ground Zero runs two level queues with their own entries and spawn rates, `ground-zero` (up to level 20) and `ground-zero-21`. A small "Lvl ≤20 / Lvl 21+" toggle in front of its pills picks one. It starts on the queue the active profile's player level lands in, until the user picks one.

Pills carry a corner glyph for conditional spawns: ☾ for night only (cultists, and Night Factory's extras) and 🎃 for the Halloween infection event (the "Infected" zombies, whose screamer variant tarkov.dev ships with no English name, and Infected Tagilla). Partisan's pill and card explain that in PvP and Seasonal his real chance rises with low-karma PMCs in the raid, quoting BSG and listing what lowers or raises karma (from the wiki's Partisan and Karma pages); the content lives in `src/features/maps/lib/partisan.ts`.

## Boss gear and loot

Every portrait in the boss strip is a button that opens a card with that boss's gear and loot. The header shows the boss's spawn chance on the current map and total HP. Below it, the left column has Gear and Health tabs: gear is grouped by worn slot (weapons first, each with the rounds seen loaded in it), and health lists max HP per body part as a small bar table with a PMC's HP alongside for comparison. Loot is split into Common (10% or more), Uncommon (1% to 10%), and Rare (under 1%) bands, with a search box and a category filter. Rare starts collapsed since it's most of the list, but a search reaches into it, so typing "rusted" finds Kaban's 0.23% Rusted bloody key directly. Any row opens the app-wide item detail popup on top of the card.

The data comes from the `mobs` collection in tarkov.dev's `maps` payload, which the game-data proxy already fetched. It's compacted on the server in `src/shared/lib/tarkov-api/mob-loadouts.ts` (the raw form is several MB) into a top-level `mobs` section of the game data. Two things about it are easy to misread:

- **Loot chance comes from tarkov.dev.** Each item's `prevalence` is tarkov.dev's own figure for how often this boss's bots carry it. Its source isn't documented, so the card calls it a rough guide, not official drop rates.
- **Gear chance is our estimate.** Upstream's `equipment` is a plain list of everything in a handful of sample loadouts tarkov.dev generates (its "renders", also used for NPC portraits), with no probability attached and no documented sample count. Counting the live data shows 15 per AI difficulty, so the card divides how often each item appears by that. With 15 samples each one moves a figure by about 7%, so gear chances are shown with a `~` and the section says they're rough estimates, not the game's real odds.

Faction pills (Black Division, AF, Rogues) combine their enemy types' data and say so. A few enemies have little or no data upstream, and the card shows an empty state for them.

### Guards and squad sizes

A boss with guards on the current map gets a row of tabs at the top of the card: the boss first, then each guard type with how many come along per spawn (Kaban on Streets: Guard ×4, Basmach ×1, Gus ×1, Sniper ×1 to 2). Picking a guard shows that guard's own Gear/Health and Loot in the same layout, while the header keeps naming the boss. A count that varies says which size is most likely when one beats the rest ("2 to 4 (most often 4)" for Reshala's guards). A faction that travels with its own kind (Raiders, Rogues, Black Division) gets no tabs; its header says the group size instead, the leader included.

This comes from each boss spawn's `escorts` in tarkov.dev's `maps` payload: every escort is a mob plus a distribution of how many spawn. `src/features/maps/lib/boss-groups.ts` turns them into guards per pill. The same mob listed twice on one spawn adds up, guards are averaged over the spawns that bring them, and the Goons are left out on purpose: Big Pipe and Birdeye are bosses with pills of their own, even though upstream lists them as Knight's escorts. Including every guard in the `mobs` section adds about 135 KB to the game data, which is fine now that the cache lives in IndexedDB.

## Where and when bosses spawn

Under its spawn chance, each boss card says where and when that boss can appear on the current map, for the active mode and Ground Zero queue:

- **Where:** the boss's spawn zones. With one spawn on the map, each zone shows its chance when that spawn happens (Reshala on Customs: Dorms, New Gas Station and Stronghold, 33% each). A faction like Raiders on Labs has many spawns, most naming a single zone, so its zones are listed by name only, likeliest first, rather than as a row of "100%". The five likeliest show and the rest fold behind "+N more". Partisan has no zones in the data; his card says he roams the whole map, as the wiki does.
- **When:** at raid start, at a random time during the raid (the Goons), from a time (Partisan from 15:00 in PvP and Seasonal), or scripted, not on a timer (Ice Breaker). A boss with spawns at several times, or spawns a switch triggers, points to the Spawn timeline instead.
- **Show on map** draws the boss's possible spawn spots as small portraits, hovering one names its zone. It first moves to a view that can place markers (the same rule as quest markers, `variantHasAccurateMarkers`), as the exit tools do. A chip under the view switcher says whose spots are shown, that they're possible spots and not sightings, and which zones list no spots, and clears them with ×. Changing the map, the mode or the Ground Zero queue clears them as well.

A **Spawn timeline** button follows the pills on any map where the active mode has a timed, random-time or switch-triggered spawn (Labs, Reserve, Terminal, and the maps the Goons and Partisan visit). It lists timed spawns in order, each spawn on its own line, and flags a time past the raid's length rather than hiding it (Terminal lists its visiting bosses at 96:30, in a 50 minute raid). Spawns a switch can trigger are grouped by switch, the Goons get a short random-time list, and the raid-start roster sits collapsed at the end. Scripted spawns aren't listed.

### What the data says, and doesn't

Everything here comes from each boss spawn in tarkov.dev's `maps` payload for each mode, joined in `src/shared/lib/tarkov-api/join-json-api-data.ts` and turned into pills and the timeline in `src/features/maps/lib/boss-groups.ts` and `boss-spawns.ts`. The meanings below were checked against tarkov.dev's data manager source on 2026-11-08:

- **Zones.** `spawnLocations` lists the spawn's zones. A zone's `chance` is its share of the game's own zone list for that spawn, so it's the chance of that zone given the spawn happens. Its `positions` are the map's spawn points inside the zone, which makes them possible spots, never observed spawns. Some zones have none (Reshala's Dorms and New Gas Station).
- **Times.** `spawnTime` is the game's own spawn time in seconds, `-1` for raid start. `9999` (Ice Breaker) and `119999` (PvE Labyrinth) are placeholders for scripted spawns, shown as such. `spawnTimeRandom` is the game's random-time flag, set only for the Goons.
- **Switches.** A spawn a switch triggers carries the game's trigger id (`switch_id`), and upstream builds each switch's name key from that same id, so the join matches the key by its `switch_{id}_` prefix. The translation pass overwrites that key with the display name, so the maps fetch copies it aside first (`keepSwitchNameKeys`). Two Labs triggers match no switch, because upstream leaves switches without a collider out of the list; the timeline groups them as other extract switches and lists a spawn they share once, since it can't tell them apart. The spawn's own `switch` hash can't be used, since upstream hashes it without the switch's object name and it never equals a switch's id.
- **Linked times.** A few triggered spawns also carry a time (Labs: the Hangar Gate Switch with 10:00, the Parking Gate Switch with 20:00). What the game does with it isn't documented, so the timeline shows it as a "linked time" without reading anything into it.

A map's spots are stored once, in `bossSpawnSpots`, keyed by zone, rounded to 0.1 m and shared by all three modes' rosters (a zone had the same spots in every mode that lists it). Storing them on each boss entry repeated every spot about five times. The spawn zones, times, triggers and spots add about 68 KB to the game data.

## Collaborative sessions

A host can start a shared session and share a join code or invite link. While active, the host's map, pan, and zoom drive everyone's view, and a guest can request control. The drawing/annotation layer is shared and color-coded by author.

Built on [Liveblocks](https://liveblocks.io), the only real-time transport in this otherwise client-only app. Requires a `LIVEBLOCKS_SECRET_KEY` env var for the server routes under `src/app/api/maps-session/` that mint room tokens and end sessions; without it, hosting or joining a session fails. Set it in `.env.local` (gitignored):

```
LIVEBLOCKS_SECRET_KEY=sk_...
```

No client-side Liveblocks key is needed; the client authenticates through this app's own token route.
