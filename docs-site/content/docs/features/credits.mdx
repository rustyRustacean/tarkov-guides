A single page attributing every third-party source this site pulls live data or bundled assets from: tarkov.dev (game data plus map imagery), the-hideout/tarkov-dev-svg-maps (SVG overview maps), the Escape from Tarkov Wiki on Fandom (quest guide text/screenshots), re3mr/reemr.se (the Ice Breaker deck plan), and TarkovBOT.eu (Ice Breaker tile imagery).

Two sources are CC BY-NC-SA (the SVG maps and the reemr.se deck plan), noncommercial use only, which is why this page exists rather than a passing footer mention: that license requires attribution wherever the work is used. Re-verify licenses against each source before relying on this for anything beyond "the site gives credit," since terms can change upstream.

This isn't a migration phase target; there's no legacy equivalent in either legacy repo. New content, same category as `faq`/`external-resources`.
